### 2026-06-06
- **当前状态**：已修复日期型页尾未被识别导致跨页错误合并问题
- **已完成任务**：
  - 修复日期型页尾未被识别导致跨页错误合并：
    - 修改 `text_analyzer.py` `_add_similar_blocks()` 短文本相似度阈值从 1.0（完全相同）降低到 0.8
    - 统一简化分级阈值（短文本 1.0 / 长短混合 0.95 / 长文本 0.9）为单一 0.8 阈值
    - 根因：原短文本阈值 1.0 过于严格，"2025年2月 8" 与 "2025年2月 9" 的 LCS 相似度 ≈ 88.9%，低于 100% 阈值，无法被识别为页脚
    - 验证："2025年2月 8" vs "2025年2月 9" 相似度 0.8889 > 0.8 ✓，"xii | Foreword" vs "xiv | Foreword" 相似度 0.9286 > 0.8 ✓
  - 修复文本框超出原文宽度/页宽度和 tight bbox 高度过大问题
  - 修复文本框超出原文宽度和页宽度：
    - 修复 `pdf_generator.py` 溢出重试逻辑：扩展文本框时限制右/下边界不超过页面宽高
    - 修复 `paddle_extractor.py` `_compute_tight_bbox()` 宽度容差从 30% 降低到 10%
    - 增加 tight bbox 页面宽度限制，防止 OCR 检测噪声导致 bbox 超出页面
  - 修复 tight bbox 高度过大：
    - 在 `_compute_tight_bbox()` 中增加高度 10% 容差限制（与宽度对称）
    - 新增 `_estimate_font_size_from_textlines()` 辅助方法，使用 textline 平均高度估算 font_size
    - 修复 5 个非 TEXT_LABELS 路径的 font_size 估算，从 `bbox_height * 0.75` 改为 textline 平均高度 * 0.75
- **技术实现**：
  - 根因分析：非语义合并路径下，PDF 生成器溢出扩展无页面宽度限制 + OCR tight bbox 宽度容差过大（30%）+ 高度无容差限制 + font_size 估算使用整个 bbox 高度（含行间距）
  - 修复策略：页面边界限制 + 容差收紧 + textline 级别精确估算
- **影响**：
  - 文本框不再超出页面边界，翻译文本渲染更精确
  - font_size 估算更准确，白色背景 padding 更合理
  - 多行文本块的 bbox 高度不再包含过多行间距
- **遇到的问题**：
  - 初始分析误判为语义合并路径的 bbox 扩展问题，用户指出未使用语义合并后重新定位根因
- **后续计划**：
  - 实际运行验证第24页文本框宽度问题是否解决
