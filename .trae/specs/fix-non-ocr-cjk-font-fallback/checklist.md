# Checklist

## 统一字体支持检测

- [x] `_check_font_support()` 不再对非 zh/ja/ko 语言直接返回 `True`
- [x] `test_chars` 字典包含所有语言的测试字符（en/de/fr/es/pt/it/zh/ja/ko/th/vi/ru/ar/hi/he 等）
- [x] 未列出的语言使用英文测试字符作为回退
- [x] 德语字体检测使用 äöüß 等特殊字符

## 原始字体目标语言支持检测

- [x] `_get_suitable_font()` 第1步中，原始字体插入成功后会检测其是否支持目标语言字符
- [x] 原始字体不支持目标语言 → 跳过，继续搜索系统字体
- [x] 原始字体支持目标语言 → 直接返回原始字体
- [x] 无法获取字体文件路径的内嵌字体 + 非拉丁目标语言 → 默认跳过
- [x] OCR路径（original_font 为空）→ 行为不变

## 端到端验证

- [ ] 非OCR翻译英文PDF为中文时，翻译文本不再显示问号
- [ ] 非OCR翻译英文PDF为英文/德语/法语时，仍使用原始字体
- [ ] 非OCR翻译英文PDF为泰语/俄语/阿拉伯语等时，翻译文本不再显示问号
