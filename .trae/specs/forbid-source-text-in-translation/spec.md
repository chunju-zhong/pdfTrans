# 禁止翻译输出原文 Spec

## Why

LLM 在翻译时偶尔会同时输出原文和目标语言翻译（如英文原文+中文翻译），导致翻译结果包含冗余的原文内容，影响最终 PDF 输出质量。当前提示词规则14"禁止元注释"仅禁止注释/说明/备注，未明确禁止输出原文。

## What Changes

- 强化规则14，明确禁止在翻译结果中包含原文内容

## Impact

- Affected code: `modules/translator.py` 的 `_generate_system_prompt` 方法（第158行）
- 影响范围：所有翻译请求

## MODIFIED Requirements

### Requirement: 强化规则14禁止输出原文

当前规则14：
```
14. **禁止元注释**：翻译结果中严禁添加任何形式的注释、说明、备注（如"注："、"说明："等），只输出翻译内容本身，不解释翻译决策。
```

修改后：
```
14. **禁止元注释和原文输出**：翻译结果中严禁添加任何形式的注释、说明、备注（如"注："、"说明："等），严禁输出原文内容，只输出{target_lang_name}翻译结果本身，不解释翻译决策，不保留原文。
```

#### 变更点

| 原文本 | 变更 |
|--------|------|
| 标题"禁止元注释" | 改为"禁止元注释和原文输出" |
| 无 | 新增"严禁输出原文内容" |
| "只输出翻译内容本身" | 改为"只输出{target_lang_name}翻译结果本身" |
| 无 | 新增"不保留原文" |

## 验证方法

- 规则14包含"禁止"、"原文"、"元注释"关键词
- 其他规则编号和内容不受影响
